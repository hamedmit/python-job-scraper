
# python-job-scraper
<div dir="rtl">
یک ابزار سبک Python برای جمع‌آوری، فیلتر و رتبه‌بندی فرصت‌های شغلی از چند منبع کاریابی.

این پروژه روند جستجوی شغل را ساده می‌کند: فرصت‌های شغلی را از منابع مختلف جمع‌آوری می‌کند، بر اساس کلمات کلیدی فیلتر و رتبه‌بندی می‌کند، موارد تکراری را حذف می‌کند و نتایج را در فایل‌های CSV ذخیره می‌کند.
</div>

🔗 **GitHub:** https://github.com/hamedmit/python-job-scraper

---

## چرا این پروژه؟

پیدا کردن یک موقعیت شغلی مناسب، به‌خصوص موقعیت‌های Remote، معمولاً نیازمند بررسی چندین سایت کاریابی و فیلتر کردن تعداد زیادی آگهی است.

این پروژه با هدف ساده‌تر کردن این فرایند ایجاد شده است؛ به این صورت که فرصت‌های شغلی از منابع مختلف جمع‌آوری شده، بر اساس تنظیمات موردنظر کاربر فیلتر و رتبه‌بندی می‌شوند و در یک محل در دسترس قرار می‌گیرند.

## تنظیمات

تنظیمات جستجو در فایل زیر قرار دارد:

```text
config/settings.json
```

برای مثال:

```json
{
    "search": {
        "keywords": [
            "AI Engineer",
            "Python"
        ],
        "remote": true,
        "sources": [
            "remotive"
        ],
        "max_results": 30,
        "min_score": 20
    }
}
```

### توضیح تنظیمات

<div dir="rtl">

* `keywords` :

 کلمات کلیدی مورد استفاده برای پیدا کردن و رتبه‌بندی شغل‌های مرتبط.
* `remote` :

 اگر `true` باشد، جستجو برای موقعیت‌های Remote انجام می‌شود. اگر `false` باشد، موقعیت‌های Remote و On-site قابل جستجو هستند. در حالت Remote، ممکن است بعضی منابعی که موقعیت Remote ارائه نمی‌کنند نتیجه‌ای برنگردانند.
* `sources` :

 منابع کاریابی مورد استفاده برای جستجو.
* `max_results` :

 حداکثر تعداد نتایجی که از منابع پشتیبانی‌شده درخواست می‌شود.
* `min_score` :

 حداقل امتیاز مورد استفاده برای مشخص کردن شغل‌هایی که به آستانه ارتباط تعیین‌شده می‌رسند.

</div>

می‌توانید این مقادیر را متناسب با نیاز خود تغییر دهید.

# راهنمای نصب و اجرا

برای اجرای مستقیم پروژه، **Python 3.10 یا بالاتر** نیاز است.

همچنین در صورت تمایل می‌توانید پروژه را با Docker اجرا کنید.

> **نکته مهم برای کاربران داخل ایران:**
> هنگام نصب وابستگی‌های Python، به‌خصوص اجرای `pip install -r requirements.txt`، حتماً از یک VPN یا ابزار دسترسی مناسب (قندشکن سایفون) استفاده کنید.

## Windows — اجرای مستقیم با Python

### 1. دریافت پروژه

ابتدا پروژه را از GitHub دریافت کنید. می‌توانید آن را با Git کلون کنید یا از گزینه **Download ZIP** در GitHub استفاده کنید.

در صورت استفاده از Git:
در پاورشل یا CMD ویندوز پس از اطمینان از نصب گیت، دستورات زیر را بزنید:

```bash
git clone https://github.com/hamedmit/python-job-scraper.git
cd python-job-scraper
```

### 2. نصب وابستگی‌ها

در پوشه اصلی پروژه، Terminal یا PowerShell را باز کنید و اجرا کنید:

```bash
pip install -r requirements.txt
```

### 3. اجرای برنامه

```bash
python main.py
```

پس از اجرا، نتایج و لاگ‌ها در پوشه `output/` ذخیره می‌شوند.

# اجرای پروژه با Docker

اگر Docker روی سیستم شما نصب است، می‌توانید پروژه را بدون نصب مستقیم وابستگی‌های Python اجرا کنید.

## Windows

در PowerShell و در پوشه پروژه اجرا کنید:

```powershell
docker compose up --build
```

پوشه `output/` به سیستم اصلی متصل است؛ بنابراین فایل‌های CSV و لاگ‌های تولیدشده بعد از اجرای Docker نیز روی سیستم شما باقی می‌مانند.

## Linux / macOS

ابتدا دسترسی اجرای فایل را فعال کنید:

```bash
chmod +x run_docker.sh
```

سپس:

```bash
./run_docker.sh
```

اسکریپت موجود در پروژه باعث می‌شود فایل‌هایی که داخل `output/` ایجاد می‌شوند، مالک کاربر فعلی سیستم باشند.

---

## خروجی‌ها

برنامه فایل‌های زیر را در پوشه `output/` نگهداری می‌کند:

* `output/jobs.csv` — شغل‌های جدید جمع‌آوری‌شده
* `output/daily/` — نتایج جمع‌آوری‌شده برای هر روز
* `output/history.csv` — تاریخچه اجرا و اطلاعات آماری مربوط به اجراها
* `output/logs/` — لاگ‌های اجرای برنامه

فایل‌های CSV را می‌توان مستقیماً با Excel یا سایر نرم‌افزارهای صفحه‌گسترده باز کرد.
